# Contributing

1. Create a branch from `main` and make changes there.
2. Keep the public API in `src/ShieldioDisplay.h` backward compatible where possible.
3. Update the demo when changing behavior.
4. Open a pull request; confirm the Arduino AVR compile check passes.
5. Test on a real SSD1306 128×64 module before marking a release stable.

This project uses MIT licensing. Please avoid importing assets without
appropriate permission and attribution. The Shieldio logo is a separate brand asset.
